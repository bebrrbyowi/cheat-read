# cheatread

Чтение по одному слову (RSVP) прямо в браузере. Веб-версия перед мобильным приложением.

## Что умеет

- Импорт книг: TXT (UTF-8, Windows-1251, UTF-16), EPUB без DRM, FB2 и FB2 в .zip, вставка текста
- Читалка с точкой фокуса, паузами на знаках препинания и плавным разгоном
- Пауза с контекстом, полный текст, переход по главам, сохранение цитат
- Быстрая сессия на 5–30 минут
- Тест темпа с вопросами на понимание
- Прогресс: время, слова, серия дней, обычный темп
- Темы светлая, бумага, ночь; шрифты Inter, Onest, Literata

Аккаунтов пока нет. Книги, цитаты и прогресс хранятся в IndexedDB этого браузера.

## Запуск

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # сборка в dist/
npm run preview   # проверить сборку
```

## Деплой

Каждый пуш в `main` публикует сайт на GitHub Pages: https://bebrrbyowi.github.io/cheat-read/

### Vercel (по желанию)

1. vercel.com → Add New → Project → импортировать этот репозиторий
2. Framework Preset: Vite (определится сам), Build: `npm run build`, Output: `dist`
3. Deploy

Роутинг на хешах (`#/library`), поэтому настройка rewrites не нужна. Сайт можно добавить на экран телефона как приложение.

## Стек

React 19, TypeScript, Vite, react-router, idb, JSZip.

```
src/
  lib/         rsvp, импорт, база, настройки, статистика
  components/  общие элементы интерфейса, дуга таймера
  screens/     экраны
  data/        тексты для теста темпа
```
